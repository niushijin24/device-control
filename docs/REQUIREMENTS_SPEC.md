# 设备管理系统需求规格说明书

## 1. 引言

### 1.1 编写目的
本文档旨在明确设备管理系统的功能需求、非功能需求及界面设计要求，为开发团队提供详细的实施指南，并作为项目验收的依据。

### 1.2 适用范围
本系统适用于需要对大量联网设备进行集中管理、监控和维护的企业或组织，主要用户包括系统管理员、运维人员和技术支持人员。

## 2. 总体描述

### 2.1 产品背景
随着物联网设备的增加，传统的人工记录和分散管理方式已无法满足需求。本系统旨在构建一个现代化的、可视化的设备管理平台，实现设备的全生命周期管理和实时状态监控。

### 2.2 用户角色
| 角色 | 描述 | 主要职责 |
| --- | --- | --- |
| **超级管理员** | 拥有最高权限 | 系统配置、用户管理、权限分配、所有设备操作 |
| **运维人员** | 负责设备维护 | 设备监控、设备增删改查、故障处理、日志查看 |
| **普通用户** | 仅查看权限 | 查看设备列表、查看设备详情、查看统计报表 |

## 3. 功能需求

### 3.1 认证与授权模块
*   **用户登录**：支持账号密码登录，集成 JWT 令牌认证机制。
*   **权限控制**：基于角色的访问控制 (RBAC)，不同角色拥有不同的菜单和操作权限。
*   **安全退出**：清除本地会话信息并跳转至登录页。

### 3.2 仪表盘 (Dashboard)
*   **数据概览**：展示设备总数、在线设备数、离线设备数、故障设备数。
*   **统计图表**：
    *   设备状态分布（饼图）。
    *   近7天设备活跃趋势（折线图）。
    *   设备类型分布（柱状图）。
*   **快捷入口**：提供常用功能的快速跳转链接。

### 3.3 设备管理模块
*   **设备列表**：
    *   展示设备名称、ID、IP地址、类型、状态、最后在线时间等信息。
    *   **状态标识**：在线（绿色）、离线（灰色）、故障（红色）、维护中（橙色）。
    *   **分页**：支持服务端分页，自定义每页显示条数。
*   **搜索与筛选**：
    *   支持按设备名称、ID 模糊搜索。
    *   支持按设备类型、状态进行精准筛选。
    *   支持多条件组合查询。
*   **设备详情**：查看设备的详细配置信息、运行状态指标（CPU/内存）、位置信息等。
*   **新增设备**：填写设备基本信息进行注册，支持表单验证。
*   **编辑设备**：修改设备名称、分组、描述等信息。
*   **删除设备**：
    *   支持单个删除（需二次确认）。
    *   支持批量选择设备进行删除。
*   **导入导出**：
    *   支持 Excel/CSV 格式批量导入设备。
    *   支持将设备列表导出为 Excel 文件。

### 3.4 设备监控模块（规划中/部分实现）
*   **实时状态**：通过轮询或 WebSocket 获取设备实时心跳状态。
*   **告警提示**：设备离线或指标异常时在界面进行醒目提示。

### 3.5 系统管理模块
*   **菜单管理**：配置系统左侧菜单结构（开发中）。
*   **用户管理**：管理后台操作员账号信息（开发中）。

## 4. 非功能需求

### 4.1 性能需求
*   **响应时间**：页面加载时间不超过 2 秒，API 接口平均响应时间不超过 500ms。
*   **并发能力**：支持至少 100 个用户同时在线操作。
*   **数据容量**：支持管理万级以上的设备数据。

### 4.2 安全需求
*   **传输加密**：所有敏感数据传输建议使用 HTTPS 协议。
*   **密码安全**：用户密码需经过 BCrypt 加密存储。
*   **接口保护**：所有非公开接口必须通过 JWT Token 验证合法性。

### 4.3 易用性需求
*   **响应式设计**：界面需适配 PC 端（1920x1080 及以上）和移动端设备（手机/平板），自动调整布局。
*   **交互体验**：提供清晰的操作反馈（成功/失败提示、加载动画）。

## 5. 技术架构

### 5.1 前端架构
*   **核心框架**：Vue 3 + Vite
*   **状态管理**：Pinia
*   **路由管理**：Vue Router
*   **UI 组件库**：Element Plus
*   **数据可视化**：ECharts
*   **HTTP 客户端**：Axios

### 5.2 后端架构
*   **核心框架**：Spring Boot 3.x
*   **持久层**：MyBatis-Plus
*   **数据库**：MySQL 8.0
*   **缓存**：Redis (可选)
*   **安全框架**：Spring Security + JWT

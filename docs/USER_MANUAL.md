# 设备管理系统用户使用手册

## 1. 系统登录
### 1.1 访问地址
推荐使用 Chrome、Edge 或 Firefox 浏览器访问系统地址（例如：`http://localhost:5173` 或实际部署地址）。

### 1.2 登录操作
1.  在登录页面输入用户名和密码。
2.  点击“登录”按钮。
3.  登录成功后将自动跳转至系统首页（仪表盘）。
    > **注意**：如果忘记密码，请联系系统管理员重置。

## 2. 界面概览 (Layout)
系统界面主要分为三个部分：
*   **左侧导航栏**：包含所有功能模块的菜单入口，支持折叠。
*   **顶部状态栏**：显示当前用户头像、系统通知、主题切换及退出登录按钮。
*   **主内容区域**：展示具体的功能页面内容。

### 2.1 移动端适配
在手机或平板访问时，侧边栏会自动隐藏。点击左上角的“汉堡菜单”图标可展开导航栏。

## 3. 仪表盘 (Dashboard)
登录后默认进入仪表盘页面。
*   **概览卡片**：顶部展示设备总数、在线/离线/故障设备数量统计。
*   **图表分析**：
    *   **左侧饼图**：直观展示设备在线、离线、故障的比例。
    *   **右侧趋势图**：显示最近一周设备的活跃度变化。
*   可以在此页面快速了解系统的整体运行健康状况。

## 4. 设备列表管理
点击左侧菜单 **“设备管理” -> “设备列表”** 进入该页面。

### 4.1 查看设备
*   页面以表格形式展示设备信息（ID、名称、IP、类型、状态、最后更新时间）。
*   **分页浏览**：列表底部提供分页控件，可切换页码或调整每页显示数量。

### 4.2 搜索设备
在列表顶部的搜索栏中：
1.  输入设备名称或设备ID。
2.  选择设备状态（在线/离线等）或设备类型。
3.  点击“搜索”按钮，列表将只显示匹配的结果。
4.  点击“重置”按钮可清空搜索条件并恢复默认列表。

### 4.3 新增设备
1.  点击列表上方的 **“新增设备”** 按钮。
2.  在弹出的对话框中填写设备信息：
    *   **设备名称**（必填）
    *   **设备类型**（下拉选择）
    *   **IP 地址**（格式需正确）
    *   **描述信息**（选填）
3.  点击“确定”保存。成功后设备将出现在列表中。

### 4.4 编辑设备
1.  在设备列表中找到目标设备。
2.  点击右侧“操作”列的 **“编辑”** 按钮。
3.  修改需要更新的信息（如修改设备名称或位置）。
4.  点击“确定”保存更改。

### 4.5 删除设备
*   **单个删除**：点击“操作”列的 **“删除”** 按钮，系统会弹出二次确认框，点击“确认”即可删除。
*   **批量删除**：
    1.  勾选列表最左侧的一个或多个复选框。
    2.  点击列表上方的 **“批量删除”** 按钮。
    3.  确认后，所选设备将被一次性删除。

### 4.6 导出数据
点击 **“导出数据”** 按钮，系统将自动下载当前设备列表的 Excel/CSV 文件到本地。

## 5. 系统设置
### 5.1 修改个人信息
点击右上角头像，选择“个人中心”可查看或修改当前登录用户的资料（功能开发中）。

### 5.2 退出登录
点击右上角头像，选择 **“退出登录”**，系统将清除登录状态并返回登录页。

## 6. 常见问题 (FAQ)
**Q: 为什么无法登录？**
A: 请检查网络连接，或确认用户名密码是否正确。如果提示“服务连接失败”，请联系技术支持检查后端服务状态。

**Q: 为什么设备状态显示不准确？**
A: 设备状态依赖于后端的心跳检测，可能存在 1-3 分钟的延迟，属于正常现象。

**Q: 手机端如何查看表格的所有列？**
A: 由于手机屏幕限制，表格不仅支持横向滚动，部分次要列可能会被自动隐藏，建议点击“详情”查看完整信息。
